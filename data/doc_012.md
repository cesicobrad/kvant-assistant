# Proposal: Petrol Chatbot Vendor Evaluation
**Prepared by:** Kvant Consulting
**For:** Petrol d.d. — Digital Transformation Office
**Date:** 2024-11-14
**Version:** 1.0
**Contact:** Tine Hribar (tine@kvant.si)

---

## Context

Petrol contracted a vendor (name withheld at Petrol's request) in early 2024 to build a customer-facing chatbot for their fuel card and fleet management services. After 9 months, Petrol's Digital Transformation team has low confidence in the system's performance — specifically: answer quality on complex fleet billing queries, hallucination rate, and the vendor's responsiveness to documented issues.

Petrol has asked Kvant to conduct an independent technical evaluation of the existing system and provide a written assessment before they decide whether to renew the vendor contract (decision deadline: January 31, 2025).

**This is a consulting engagement, not a build project.**

**Fixed fee: €7,800**
**Duration: 3 weeks**

---

## What We Will Do

**Week 1 — Structured testing:**
We will design and run a 50-question evaluation set covering Petrol's primary chatbot use cases (fuel card queries, fleet account management, invoice questions, station location). We will test for answer accuracy, source citation behavior (does it cite, and are citations correct?), refusal behavior on out-of-scope questions, and response consistency (same question asked multiple times — does it give the same answer?).

**Week 2 — Architecture review:**
We will review whatever technical documentation the vendor provides — architecture diagrams, system prompts, retrieval configuration if RAG is used, model choice and rationale. We will identify gaps between what was contracted and what appears to be implemented.

**Week 3 — Report and recommendations:**
Written evaluation report covering: quantitative performance on our test set, identified failure modes with examples, assessment of whether issues are fixable within the existing architecture, and a vendor-neutral recommendation (renew and fix / rebuild / replace).

---

## Deliverable

A written report, approximately 8–12 pages, suitable for presentation to Petrol's board-level Digital Transformation committee. Kvant will present the findings in person if requested (travel to Ljubljana; included in fee).

---

## What This Is Not

We are not auditing the vendor's commercial practices or contract compliance. We are not providing legal advice. We are not guaranteeing that our test set covers all use cases. This is a technical performance evaluation based on a structured sample.

If Petrol subsequently decides to rebuild or replace the system and wishes to engage Kvant for that work, we will scope that separately. We will not use this evaluation engagement to unfairly favor a Kvant-build outcome in the recommendation — the recommendation will reflect what we find.

---

## Assumptions

Petrol provides: access to the live chatbot, the vendor's technical documentation (or as much as the vendor is willing to share), and at least one internal SME for a 2-hour session on Petrol's use case priorities. If vendor documentation is withheld entirely, the architecture review will be based on behavioral testing only — we will note this limitation in the report.
